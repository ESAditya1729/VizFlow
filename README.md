# VizFlow

VizFlow is a Visual Studio Code extension for analyzing CSV files directly inside the editor.

## Features

- Sum a column
- Average of a column
- Minimum value
- Maximum value
- Count values
- Find duplicate values
- Column statistics
- CSV parsing with automatic numeric detection
- Dedicated VizFlow Output panel

## Usage

1. Open a CSV file.
2. Press `Ctrl + Shift + P`.
3. Run any VizFlow command.

Examples:

- VizFlow: Sum
- VizFlow: Average
- VizFlow: Find Duplicate Values
- VizFlow: Column Statistics
